New-night wizard progress. Mirrors the app's `night/Stepper` (dots + mono labels replaced by a segmented bar with sentence-case labels).

Steps, in order: **Date** (when the night is), **People** (who's coming), **Movie** (the picker's film) and **Done**. Labels are plain nouns for what each step sets, in sentence case.

```jsx
<Stepper current={1} />
```
