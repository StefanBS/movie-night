Initials on the member's signature colour ("Film stock" palette, white initials). Mirrors the app's `Avatar` (and `lib/avatar.ts` hashing into `--sig-1…7`).

```jsx
<Avatar name="Tomas Vlk" size="lg" />
<Avatar name="Priya Nair" size={28} />
```

No ring, glow or ember on avatars. The picker is marked by their name (size/weight) and the `Next up` badge. Elsewhere the signature colour can appear as an 8–10px dot beside a name (lists, history).
