Film poster. Mirrors the app's `Poster`. Posters are the main source of colour in the app — show them untreated, 2:3, 4px radius.

```jsx
<Poster uri={movie.posterUrl} title="Past Lives" year={2023} w={106} h={159} />
<Poster title="Heat" hue={210} />
```

Pair with the film title in `--font-serif` italic.
