Round icon-only tap target. Pass a Lucide glyph (2px stroke, 18–20px) as children.

```jsx
<IconButton label="Settings" filled><SettingsIcon /></IconButton>
<IconButton label="Previous month" size="sm"><ChevronLeft /></IconButton>
```

Sizes `sm` (32) | `md` (40). `filled` for top-bar actions. Always pass `label`.
